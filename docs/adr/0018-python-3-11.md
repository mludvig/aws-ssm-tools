# 0018. Require Python 3.11

## Status
Accepted (2026-11-25)

## Context
Python 3.10 reached end of life in October 2026. On 3.10, the lockfile is stuck on filelock 4.1.0, a dev dependency through hatch and virtualenv with 17 Dependabot alerts. The fix, filelock 4.2.1, needs Python 3.11.

## Decision
3.0.0 requires Python 3.11 or later. CI tests 3.11–3.15 and builds on 3.11. `ssm-tunnel-agent` is unchanged; it runs on the instances, not on the client.

## Consequences
- 3.10 users get 2.2.1 from pip. The 3.0.0 release notes list this as a breaking change.
- **Alternative rejected:** keep 3.10 and dismiss the alerts. That means supporting an end-of-life Python, and the alerts would come back with every lock update.
